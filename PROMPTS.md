# Prompt

Create a responsive "Past Highlights" section for a developer conference website called **DevConf 2026**.

Requirements:
- Use only HTML and CSS.
- Display four statistic cards in a single row on desktop:
  - Attendees: 4,000+
  - Speakers: 50+
  - Countries: 30+
  - Sessions: 120+
- Use a blue background that is visually distinct from the footer while matching the website's overall dark/light theme.
- Reuse the existing `.section-title` and `.section-subtitle` CSS classes for consistency.
- Make the section fully responsive:
  - 4 columns on desktop
  - 2 columns on mobile
- Keep the HTML and CSS clean, compact, and easy to integrate into an existing `index.html` and `style.css`.
- Use modern CSS Grid for the layout with evenly spaced cards and subtle rounded corners.
